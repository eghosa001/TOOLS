## Creative direction — short captivating child-friendly originals

**Working title only:** Tiny Trails, Big Surprises (not confirmed commercially unique). Main audience **4–8**. First pilot **90–110 seconds**; following episodes normally **90–150 seconds**, about **140–230 spoken words** unless predominantly visual. No unnecessary long introductions, repeated explanatory dialogue, filler, moral lectures, frightening stakes, embarrassing humor or oversized cast.

- Start in **5–8 seconds** with a funny visual hook or clear mystery.
- Establish **one understandable goal** within about 20 seconds.
- Include **two escalating playful complications** with expressive 3D actions.
- Finish with an earned observation/collaboration solution and a quick funny payoff. End promptly.
- Use one visually coherent setting per pilot. Do not arbitrarily mix different source-film styles or stuff all twenty into one video.
- Proposed first leads: **Sprite + Elder Sprite**. They share first-party film art style and have actually moving source jaws. **Rex** is a guest only when visually compatible. Other unverified performers remain silent/background until facial and audio performance prove otherwise.
- Proposed pilot (not canon screenplay yet): **The Leaf That Wouldn't Stay**; one leaf, two speaking leads, one woodland clearing, playful breeze problem and an affectionate visual twist.
- New series character personality, voice, relationships, location and story details are only confirmed canon after user approval.

## Character licensing and release rules

Reuse original artist character rigs/files, available animations, materials and environment assets wherever compatible; do not hand-model a replacement for a free usable rig. Record original creator, source URL, exact licensed rights, file SHA-256, tested Blender version and actual Kaggle mount path. Blender Studio CC-BY sources require attribution. Vitruvian original CC0 sources do not convey blanket redistribution rights to third-party motion. Do not put raw source assets in public GitHub if their redistribution rights are unclear. Project Sources describe assets but are not Kaggle input mounts.

Before preview, prepare exact story JSON **for the new series separately**, asset mapping, scene list, dialogues keyed by speaker, durations, voice/license proof and known limits. Legacy video/story.json remains unchanged until the user explicitly directs otherwise.

Only if the user approves the preview and explicitly selects full, submit a full render. Kaggle token stays exclusively in GitHub Actions Secrets under KAGGLE_API_TOKEN; repo is public.
