# Free historical documentary assets and add-ons
Catalogued sources are NOT claims that files have been downloaded.

| Source | Intended use | Rights caution |
|---|---|---|
| https://polyhaven.com | realistic HDRIs, PBR and props | CC0; live API must display "Powered by Poly Haven" |
| https://quaternius.com/packs/universalanimationlibrary.html | humanoid animation | CC0 standard library; retarget to rigs |
| https://quaternius.com/packs/medievalvillagemegakit.html | modular medieval buildings | free Standard subset CC0; stylized and not historically exact |
| https://kenney.nl/assets/castle-kit | stylized map/castle diagrams | CC0, not photorealism |
| https://ambientcg.com | realistic materials | CC0 |
| https://www.si.edu/openaccess | real historical objects and 3D scans | item-level CC0 confirmation |
| https://www.loc.gov/free-to-use/ | authentic archival illustrations | per-item rights verification |
| https://commons.wikimedia.org | archival / public domain images | per-file rights and attribution |

Manual Blender add-on installation only, never arbitrary remote code installed in CI:
- Poly Haven Online: https://extensions.blender.org/asset-libraries/poly-haven/ (Blender 5.3+)
- AutoCam Free cinematic camera paths: https://extensions.blender.org/add-ons/autocam/
- BlenderKit/Blendkit free asset discovery: https://github.com/BlenderKit/Blendkit (per-item licences vary)
- Blender native Rigify, camera tracking, compositor, Geometry Nodes and video sequencer.

Keep per-file SHA-256, license URL, creator, applicable credit, archive vs generated label, geographic/era suitability, and a locally accessible storage path. Never pass off cinematic reconstructions as real historical photography. Never redistribute artist source files unless the rights permit.
