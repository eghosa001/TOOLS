# Free documentary animation assets and add-ons (26 Oct 2026)

**Download claims:** Listed resources are potential free tools and asset sources, not proof all exact files are downloaded. The old pipeline downloaded CC0 Quaternius/Poly Haven/Kenney components through GitHub Actions, but downloadable assets are not checked into Git. Verify the current artifact-retention status before relying on them.

### Real 2D production tools

| Tool | Purpose | Licence |
|---|---|---|
| [Krita](https://krita.org) | Paint historically checked layered illustration, facial expressions and costumes | GPL application; commercial artwork allowed |
| [Inkscape](https://inkscape.org) | Vector character components, maps and iconography | GPL app; output rights depend on incorporated content |
| [Synfig](https://www.synfig.org) | Optional vector puppet tweens/2D editor | GPL software; commercial film allowed |
| [OpenToonz](https://opentoonz.github.io/e/index.html) | Manual high-quality 2D clean-up and animation | Modified BSD source; confirm per-bundled resources |
| [Rhubarb Lip Sync](https://github.com/DanielSWolf/rhubarb-lip-sync) | Free CLI accurate(ish) phoneme mouth cues from WAV | MIT software; generated cues owned by producer |
| [Godot](https://godotengine.org) | Optional GPU-accelerated Skeleton2D/Movie Maker stage | MIT software, artwork rights separate |
| [FFmpeg](https://ffmpeg.org) | Sound, encoding, concatenation, captions | Varies by build; commercial delivery widely used |
| [Piper TTS](https://github.com/OHF-Voice/piper1-gpl) | Offline CPU narration | Engine GPL-3.0 current; **each voice model has distinct rights** |

### Free reusable 2D illustrated sets/props/backgrounds

- **[Kenney](https://kenney.nl/assets)** — CC0 2D map/prop/UI/game environment kits; exact pack suitability and art style must be checked before use.
- **[OpenGameArt](https://opengameart.org)** — filter individually for **CC0** or relevant permissive licence; do not mix incompatible styles or use without item licence record.
- **[Wikimedia Commons](https://commons.wikimedia.org)** — individually cleared historical maps, artwork and documentary references (licences vary per item).
- **[Smithsonian Open Access](https://www.si.edu/openaccess)** — real historical scans/photos where item explicitly states CC0.
- **[Library of Congress](https://www.loc.gov/free-to-use/)** — check item rights; not everything is free to reuse.
- **[Poly Haven](https://polyhaven.com)** and **[ambientCG](https://ambientcg.com)** — CC0 surfaces/HDRIs, useful in optional 3D/painterly composites, not a source of automatically accurate historical scenes.
- **[Quaternius](https://quaternius.com)** — free CC0 animation/medieval assets already catalogued; mainly optional 3D reference, **not directly 2D riggable**.

### Rights and accuracy

Keep SHA-256, full rights URL, creator, historical period, attribution text and a durable local copy for **each** external PNG, model, sound and song. A CC0 medieval village illustration is not proof of historical architecture in a specific empire. Avoid copied modern movie designs, protected images and unlicensed synthetic voices. Do not install random executable Blender/Godot/Krita plugins from unsigned sources in CI.

The 2D demo cut-out character layers are drawn by this project but deliberately look basic. They must be replaced with high-quality original commissioned or artist-approved layers before attempting channel-quality publication.
