# Preserved historical and experimental paths

**Do not delete old work.** v01-v12 concepts, puppet studies, 3D templates, Grease Pencil tests and private Kaggle notebooks remain useful development evidence but cannot count as an approved final animation without signed image-by-image art review.

Old workflow categories no longer accepted for mainline release:
- direct text-to-video or image-to-full-video experiments;
- unapproved morphing, random frame invention and off-model actor generation;
- 3D character rig renders passed off as premium finished hand-drawn acting;
- exported MP4s accepted as proof without key drawings, in-betweens and a frame-sequence ledger.

Why this is a policy archive rather than a destructive move: the existing TOOLS monorepo has ongoing separate audio, staging, Kaggle and Blender technical tests; moving shared code or workflows would break them. None of these legacy tools are authorized as a production release route. Older README content is preserved as previous_README.md for traceability.

To retire a specific legacy script, verify that no other current workflow imports/calls it, tag the last version, and relocate only after replacing its legitimate functions. Keep references to the Drive experiment folder instead of publishing private concept images.
