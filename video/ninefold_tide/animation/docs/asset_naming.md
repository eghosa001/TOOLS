# Naming, versioning and ownership

Episode: E101, E102. Camera: CAM03B. Shot identifier: E101_CAM03B. Do not reuse an identifier for another camera setup.

Preferred private working layout:
- E101/CAM03B/brief/shot.json and director notes
- references/ for approved copies and provenance
- keys/E101_CAM03B_KEY_F000017_v01.png
- breakdowns/E101_CAM03B_BD_F000029_v01.png
- inbetweens/E101_CAM03B_IB_F000031_v01.png
- cleanup/E101_CAM03B_CL_F000031_v01.png
- paint/E101_CAM03B_PT_F000031_v01.png
- comp/E101_CAM03B_COMP_F000031_v01.png
- export/frames/frame_000001.png through frame_NNNNNN.png
- review/ for checklist, SHA ledgers, full-size face/hand crops and approved revision decisions

Use zero-padded six-digit frame numbers; an explicitly held drawing may appear on multiple output frames. Preserve source file revisions, copyright or license status, editor, reviewer, date and source checksum. Record whether a revision supersedes an earlier one. Never overwrite an approved image without increasing the version.

GitHub contains **manifest templates and policies only**; private Drive/local workspace owns the actual large art assets.
