# The Ninefold Tide — Full-cast engineering pass (31 October 2026)

This is an **original 2D character cutout/art-intake framework** for all **20 canon recurring roles** and **15 six-layer environment staging slots**, not a 20-character finished-animation claim. The 15 world slots are *not yet mapped* to the old anonymous scene structures. Naya's distinct private Phase20/26 art-source rig remains preserved separately.

## Built here

- `godot/scenes/cast/`: 20 individually loadable Godot 4.7.2 scene files, each with a named 15-part joint hierarchy, six engineering movement poses, fixed rotation constraints and five-view private-art binding slots. Missing images stay missing (not synthesized or cloned). All tested at engine level in GitHub Actions.
- `godot/scenes/sets/`: 15 individually loadable Godot scenes with independent six-layer compositing/occlusion order. Missing paint remains invisible.
- `godot/data/production_inventory.json`: names, known physical characteristics, source status, artwork requirements and hard `false` final production approvals. Supervisor Ren's appearance remains proposal-stage.
- `godot/tests/all_cast_and_sets_smoke.gd`: native engine tests every scene and geometry-only pose, limits, missing-art detection and output gating.
- `tests/test_inventory.py`: reproducible Python structural and canon checks.
