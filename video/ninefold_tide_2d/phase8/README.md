# Ninefold Tide — moving-rig software validation (Phase 8)

This draft contains a real **Godot 4.7.2 engine smoke** project with the revised rig script, deterministic pose/expression test, and **QA-only synthetic art**. It tests whether movement can preserve source art without stretching and whether the initial joint positions align.

[Phase 8 full production package](sandbox unavailable in GitHub; shared as conversation download). The smoke ZIP is committed in this folder to keep the engine test small.

**The mock is not a canon character design and must never be substituted for one.** The actual 20 cast rig structures still lack their individually approved final painted part images. Full animation-art production is blocked until these illustrations exist. This validation does not claim TV-quality character animation.
